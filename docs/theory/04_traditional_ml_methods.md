## 1. 机器学习在材料科学中的应用

### 1.1 发展历程

机器学习在材料科学中的应用经历了以下阶段：

**第一阶段（2000-2010）：探索期**
- 简单的线性回归和统计模型
- 小规模数据集（< 100 样本）
- 应用于合金、半导体等传统材料

**第二阶段（2010-2015）：发展期**
- 引入随机森林、支持向量机等算法
- 中等规模数据集（100-1000 样本）
- 开始应用于 MOF、COF 等多孔材料

**第三阶段（2015-2020）：成熟期**
- 集成学习方法（XGBoost、LightGBM）
- 大规模数据集（> 10,000 样本）
- 高通量计算与机器学习结合

**第四阶段（2020-至今）：智能期**
- 深度学习、图神经网络
- 超大规模数据库（> 100,000 样本）
- 主动学习、迁移学习

### 1.2 应用模式

在 MOF 研究中，机器学习主要有三种应用模式：

```
┌─────────────────────────────────────────────────────────┐
│                  机器学习应用模式                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 性质预测 (Property Prediction)                      │
│     输入: MOF 结构特征                                   │
│     输出: 吸附量、稳定性、电导率等                       │
│                                                         │
│  2. 结构筛选 (Structure Screening)                      │
│     输入: 大量候选 MOF                                   │
│     输出: 满足性能要求的 MOF 子集                        │
│                                                         │
│  3. 逆向设计 (Inverse Design)                           │
│     输入: 目标性质                                       │
│     输出: 满足要求的 MOF 结构                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.3 为什么使用机器学习？

**传统方法的局限：**
- DFT 计算耗时（单个 MOF 可能需要数小时至数天）
- 实验合成成本高、周期长
- MOF 结构空间巨大（理论上可达 10^6 - 10^18 种）

**机器学习的优势：**
- 快速预测（毫秒级）
- 低成本筛选
- 发现非线性关系
- 处理高维数据

## 2. MOF 结构-性质关系建模

### 2.1 QSPR/QSAR 方法

**QSPR (Quantitative Structure-Property Relationship)**
定量结构-性质关系，建立 MOF 结构描述符与性质之间的数学模型。

**基本框架：**

```
结构 → 特征提取 → 机器学习模型 → 性质预测

CIF文件 → [几何特征 + 化学特征 + 拓扑特征] → [训练算法] → [目标性质]
```

**数学表达：**

```
Property = f(Structure Features)

例如：
CO₂ 吸附量 = f(比表面积, 孔体积, 孔径, 官能团, ...)
```

### 2.2 特征-性质关系示例

**示例 1：CO₂ 吸附与孔结构**

| 特征 | 对 CO₂ 吸附的影响 | 重要性 |
|-----|------------------|--------|
| 比表面积 | 正相关（提供吸附位点） | ⭐⭐⭐⭐⭐ |
| 孔体积 | 正相关（容纳更多分子） | ⭐⭐⭐⭐ |
| 最大孔径 | 弱相关（需适中） | ⭐⭐⭐ |
| 密度 | 负相关（高密度意味着低孔隙率） | ⭐⭐⭐⭐ |

**示例 2：CH₄/CO₂ 选择性与化学环境**

```
选择性 ∝ f(极性, 电荷分布, 官能团)

- 极性官能团 (-OH, -NH₂) → 提高 CO₂ 选择性
- 疏水性框架 → 提高 CH₄ 选择性
- 开放金属位点 → 显著影响选择性
```

### 2.3 建模策略

**单任务学习 (Single-Task Learning):**
```
一个模型预测一个性质
- 模型 1: 预测 CO₂ 吸附
- 模型 2: 预测 CH₄ 吸附
- 模型 3: 预测选择性
```

**多任务学习 (Multi-Task Learning):**
```
一个模型同时预测多个相关性质
- 模型: 同时预测 CO₂ 和 CH₄吸附
- 优势: 共享特征表示，提高泛化能力
```

## 3. 特征工程基础

### 3.1 特征类型

**1. 几何特征 (Geometric Features)**

```python
几何特征示例：
{
    'volume': 5432.1,              # 晶胞体积 (Å³)
    'density': 0.876,              # 晶体密度 (g/cm³)
    'pld': 6.5,                    # 孔限制直径 (Å)
    'lcd': 12.3,                   # 最大腔体直径 (Å)
    'surface_area': 2500,          # 比表面积 (m²/g)
    'void_fraction': 0.72,         # 孔隙率
    'pore_volume': 0.95            # 孔体积 (cm³/g)
}
```

**2. 化学特征 (Chemical Features)**

```python
化学特征示例：
{
    'metal_type': 'Zn',            # 金属中心
    'linker_length': 11.2,         # 连接体长度 (Å)
    'functional_groups': ['OH', 'NH2'],  # 官能团
    'electronegativity_mean': 2.5, # 平均电负性
    'atomic_mass_mean': 45.3,      # 平均原子量
    'num_metal_sites': 4,          # 金属位点数
    'C_ratio': 0.45,               # 碳原子比例
    'O_ratio': 0.25,               # 氧原子比例
    'N_ratio': 0.10                # 氮原子比例
}
```

**3. 拓扑特征 (Topological Features)**

```python
拓扑特征示例：
{
    'topology_code': 'pcu',        # 拓扑类型
    'coordination_number': 4,       # 配位数
    'node_degree': 3,              # 节点度
    'dimensionality': 3,           # 维度
    'symmetry_group': 'Fm-3m'      # 空间群
}
```

### 3.2 特征缩放

**为什么需要特征缩放？**

```
原始特征范围差异大：
- 比表面积: 500-5000 m²/g
- 密度: 0.2-2.0 g/cm³
- 孔径: 3-30 Å

→ 某些算法（如SVM、KNN）对尺度敏感
→ 需要归一化处理
```

**常用缩放方法：**

**1. 标准化 (Standardization)**
```python
X_scaled = (X - μ) / σ

# 结果：均值=0, 标准差=1
# 适用于：正态分布数据
```

**2. 归一化 (Normalization)**
```python
X_scaled = (X - X_min) / (X_max - X_min)

# 结果：范围 [0, 1]
# 适用于：有明确上下界的数据
```

**3. 鲁棒缩放 (Robust Scaling)**
```python
X_scaled = (X - median) / IQR

# IQR: 四分位距
# 优势：对异常值不敏感
```

### 3.3 特征选择

**目的：**
- 减少冗余特征
- 提高模型性能
- 降低过拟合风险
- 提升可解释性

**方法：**

**1. 过滤法 (Filter Methods)**
```python
# 基于统计检验
- 相关系数筛选
- 方差阈值
- 卡方检验

优点：快速、独立于模型
缺点：忽略特征间交互
```

**2. 包裹法 (Wrapper Methods)**
```python
# 基于模型性能
- 递归特征消除 (RFE)
- 序列特征选择

优点：考虑特征交互
缺点：计算成本高
```

**3. 嵌入法 (Embedded Methods)**
```python
# 模型内置
- Lasso (L1 正则化)
- 树模型特征重要性
- SHAP 值

优点：平衡性能与效率
```

## 4. 常用机器学习算法

### 4.1 线性回归 (Linear Regression)

**原理：**
```
y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε

y: 目标变量（如 CO₂ 吸附量）
x: 特征变量（如比表面积、孔体积）
β: 回归系数
ε: 误差项
```

**优点：**
- 简单、可解释性强
- 训练快速
- 适合线性关系

**缺点：**
- 无法捕捉非线性关系
- 对异常值敏感
- 假设特征独立

**适用场景：**
- 探索性分析
- 基准模型
- 特征筛选

**扩展：**

**岭回归 (Ridge Regression):**
```
损失函数 = MSE + α Σβ²

- L2 正则化，防止过拟合
- 保留所有特征，但缩小系数
```

**Lasso 回归:**
```
损失函数 = MSE + α Σ|β|

- L1 正则化，特征选择
- 某些系数变为 0
```

**弹性网 (Elastic Net):**
```
损失函数 = MSE + α₁Σ|β| + α₂Σβ²

- 结合 L1 和 L2
```

### 4.2 支持向量机 (SVM)

**原理：**

对于回归任务（SVR），找到一个函数 f(x)，使得大部分训练样本到该函数的距离小于 ε：

```
最小化: 1/2 ||w||² + C Σξᵢ

约束条件:
|yᵢ - f(xᵢ)| ≤ ε + ξᵢ
```

**核函数 (Kernel Functions):**

```python
# 线性核
K(x, x') = x · x'

# 多项式核
K(x, x') = (γx · x' + r)^d

# RBF (径向基函数) 核
K(x, x') = exp(-γ||x - x'||²)

# Sigmoid 核
K(x, x') = tanh(γx · x' + r)
```

**超参数：**
- `C`: 正则化参数（越大越严格）
- `ε`: 容忍误差
- `γ`: 核函数参数（RBF）

**优点：**
- 处理非线性关系
- 高维空间有效
- 泛化能力强

**缺点：**
- 计算成本高（大数据集）
- 超参数调优复杂
- 可解释性差

**适用场景：**
- 中小规模数据集 (< 10,000 样本)
- 复杂非线性关系
- 需要高精度预测

### 4.3 随机森林 (Random Forest)

**原理：**

集成多个决策树，通过投票或平均得到最终预测：

```
      [训练集]
         |
    随机采样 + 随机特征
         |
    ┌────┴────┐
   树1  树2  ... 树n
    └────┬────┘
         |
      平均/投票
         ↓
       [预测]
```

**关键机制：**

**1. Bagging (Bootstrap Aggregating)**
```python
# 对每棵树：
1. 从训练集中有放回抽样（约 63% 样本）
2. 使用抽样数据训练决策树
3. 重复 n_estimators 次
```

**2. 特征随机性**
```python
# 每次分裂节点时：
- 随机选择 max_features 个特征
- 从中选择最佳分裂特征
- 增加树的多样性
```

**超参数：**

```python
重要超参数：
- n_estimators: 树的数量（通常 100-1000）
- max_depth: 树的最大深度
- min_samples_split: 分裂所需最小样本数
- min_samples_leaf: 叶节点最小样本数
- max_features: 每次分裂考虑的特征数
  - 'sqrt': √n_features （分类）
  - 'log2': log₂(n_features)
  - 0.3-0.5: 30%-50% 特征（回归）
```

**优点：**
- 强大的非线性拟合能力
- 对异常值和噪声鲁棒
- 特征重要性评估
- 无需特征缩放
- 并行训练

**缺点：**
- 可能过拟合（需调参）
- 模型文件较大
- 对线性关系不如线性模型

**适用场景：**
- 通用场景（性能稳定）
- 需要特征重要性分析
- 数据存在噪声

### 4.4 梯度提升树 (Gradient Boosting)

**原理：**

顺序训练多个弱学习器，每个新树修正前面树的错误：

```
F₀(x) = 初始预测（通常是均值）

For m = 1 to M:
    1. 计算残差: rᵢ = yᵢ - F_{m-1}(xᵢ)
    2. 训练新树 h_m(x) 拟合残差
    3. 更新模型: F_m(x) = F_{m-1}(x) + η·h_m(x)

最终模型: F(x) = F₀(x) + η Σh_m(x)
```

**XGBoost (Extreme Gradient Boosting)**

**特点：**
- 正则化（L1 + L2）防止过拟合
- 并行计算（特征级并行）
- 缺失值处理
- 树剪枝（max_depth）
- 早停机制

**关键超参数：**

```python
{
    'n_estimators': 100-1000,      # 树的数量
    'learning_rate': 0.01-0.3,     # 学习率 η
    'max_depth': 3-10,             # 树深度
    'subsample': 0.5-1.0,          # 样本采样率
    'colsample_bytree': 0.5-1.0,   # 特征采样率
    'reg_alpha': 0-1,              # L1 正则化
    'reg_lambda': 1-10,            # L2 正则化
    'min_child_weight': 1-10,      # 叶节点最小权重和
    'gamma': 0-5                   # 分裂最小损失减少
}
```

**LightGBM (Light Gradient Boosting Machine)**

**特点：**
- 基于直方图的算法（更快）
- 叶子生长策略（Leaf-wise）
- 类别特征原生支持
- 内存占用更小

```
XGBoost: Level-wise 生长
      O
    /   \
   O     O
  / \   / \
 O   O O   O

LightGBM: Leaf-wise 生长
      O
    /   \
   O     O
  / \
 O   O
    / \
   O   O
```

**关键超参数：**

```python
{
    'n_estimators': 100-1000,
    'learning_rate': 0.01-0.3,
    'num_leaves': 20-100,          # 叶子数（而非深度）
    'max_depth': -1 或 3-10,
    'subsample': 0.5-1.0,
    'colsample_bytree': 0.5-1.0,
    'reg_alpha': 0-1,
    'reg_lambda': 0-1,
    'min_child_samples': 10-100    # 叶节点最小样本数
}
```

**CatBoost (Categorical Boosting)**

**特点：**
- 处理类别特征无需编码
- 有序提升（Ordered Boosting）
- 对称树
- 更少的过拟合

**优点（梯度提升系列）：**
- 预测精度高（通常是最优）
- 灵活性强
- 特征重要性评估
- 处理缺失值

**缺点：**
- 训练时间长（顺序训练）
- 超参数多，调优复杂
- 容易过拟合（小数据集）
- 可解释性较差

**适用场景：**
- 竞赛级别精度要求
- 表格数据（结构化数据）
- 大规模数据集
- 特征交互复杂

## 5. 模型评估与验证

### 5.1 评估指标

**回归任务指标：**

**1. R² (决定系数)**
```
R² = 1 - (SS_res / SS_tot)
   = 1 - Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)²

范围: (-∞, 1]
- R² = 1: 完美预测
- R² = 0: 与平均值预测相当
- R² < 0: 比平均值还差

优点：无量纲，易于理解
缺点：添加特征总会提高 R²（即使无用特征）
```

**2. MSE (均方误差)**
```
MSE = (1/n) Σ(yᵉ - ŷᵢ)²

单位：目标变量单位的平方
特点：
- 对大误差敏感（平方惩罚）
- 不易直观理解
```

**3. RMSE (均方根误差)**
```
RMSE = √MSE = √[(1/n) Σ(yᵢ - ŷᵢ)²]

单位：与目标变量相同
特点：
- 与原始数据同尺度
- 对大误差敏感
- 最常用的指标
```

**4. MAE (平均绝对误差)**
```
MAE = (1/n) Σ|yᵢ - ŷᵢ|

单位：与目标变量相同
特点：
- 对异常值不敏感
- 直观易懂
```

**5. MAPE (平均绝对百分比误差)**
```
MAPE = (100/n) Σ|yᵢ - ŷᵢ| / |yᵢ|

单位：百分比
特点：
- 相对误差
- 不适用于 yᵢ = 0 的情况
```

**选择建议：**

```python
推荐组合：
主要指标: R² + RMSE
辅助指标: MAE

对于 MOF 吸附预测：
- RMSE: 评估预测精度
- R²: 评估拟合优度
- MAE: 评估典型误差
```

### 5.2 交叉验证

**目的：**
- 更可靠的性能评估
- 减少过拟合风险
- 充分利用有限数据

**K-折交叉验证 (K-Fold CV)**

```
数据集分为 K 份：

折1   折2   折3   折4   折5
├────┼────┼────┼────┼────┤
│    │    │    │    │    │

迭代1: [测试][────训练─────]
迭代2: [训练][测试][──训练──]
迭代3: [──训练──][测试][训练]
迭代4: [────训练─────][测试]
迭代5: [训练][──训练──][测试]

最终得分 = 5次得分的平均值
```

**常用 K 值：**
- K=5: 平衡偏差与方差（最常用）
- K=10: 更稳定的估计
- K=n (留一法): 小数据集

**分层 K 折 (Stratified K-Fold)**

```python
# 对于分类任务，保持各类别比例
# 对于回归任务，保持目标值分布

适用于：
- 数据不平衡
- 样本量小
```

**时间序列交叉验证**

```
时间 ──────────────────────>

训练1 [────] [测试1]
训练2 [────────] [测试2]
训练3 [──────────────] [测试3]

特点：
- 保持时间顺序
- 避免未来信息泄露
```

### 5.3 训练/验证/测试集划分

**标准划分：**

```
原始数据集
    |
    ├─ 训练集 (60-80%)
    |    └─> 用于训练模型
    |
    ├─ 验证集 (10-20%)
    |    └─> 用于超参数调优
    |
    └─ 测试集 (10-20%)
         └─> 最终性能评估（只用一次！）
```

**推荐方案：**

```python
# 方案 1: 小数据集 (< 1000 样本)
训练集: 70%
测试集: 30% + 5折交叉验证

# 方案 2: 中等数据集 (1000-10000)
训练集: 60%
验证集: 20%
测试集: 20%

# 方案 3: 大数据集 (> 10000)
训练集: 80%
验证集: 10%
测试集: 10%
```

### 5.4 过拟合与欠拟合

**识别方法：**

```
学习曲线分析：

过拟合：
训练误差 ──────────> 很低
验证误差 ─ ─ ─ ─>  高且不下降

欠拟合：
训练误差 ──────────> 高
验证误差 ─ ─ ─ ─>  高

理想情况：
训练误差 ──────\___> 低
验证误差 ─ ─ ─\___> 低且接近训练误差
```

**解决方案：**

| 问题 | 解决方法 |
|-----|---------|
| 过拟合 | • 增加训练数据<br>• 简化模型（降低复杂度）<br>• 正则化（L1/L2）<br>• Dropout（神经网络）<br>• 早停（Early Stopping）<br>• 特征选择 |
| 欠拟合 | • 使用更复杂的模型<br>• 增加特征<br>• 特征工程<br>• 减少正则化<br>• 增加训练迭代 |

## 6. 可解释性分析

### 6.1 为什么需要可解释性？

**科学研究角度：**
- 理解结构-性质关系
- 发现新的设计规律
- 验证物理化学机制

**工程应用角度：**
- 建立信任（为什么相信预测？）
- 故障诊断（预测错误的原因）
- 指导优化（如何改进 MOF 设计？）

### 6.2 特征重要性

**基于树模型的重要性**

```python
# 原理：特征用于分裂时的增益累加

重要性计算：
对于每个特征 f:
    importance(f) = Σ (分裂增益 × 使用该特征的次数)

归一化：
    importance(f) / Σ importance(all features)
```

**排列重要性 (Permutation Importance)**

```python
算法：
1. 在测试集上计算基线性能 S
2. 对于每个特征 f:
    a. 随机打乱特征 f 的值
    b. 计算新性能 S'
    c. 重要性 = S - S'
3. 重复多次取平均

优点：
- 模型无关（适用于任何模型）
- 考虑特征交互
```

### 6.3 SHAP (SHapley Additive exPlanations)

**理论基础：**

来自博弈论的 Shapley 值，公平分配每个特征的贡献。

**核心思想：**

```
预测值 = 基线值 + 特征1的贡献 + 特征2的贡献 + ...

f(x) = φ₀ + φ₁ + φ₂ + ... + φₙ

φᵢ = 特征 i 的 SHAP 值（可正可负）
```

**SHAP 值计算：**

```
φᵢ = Σ [weight × (f(S∪{i}) - f(S))]
    S⊆N\{i}

遍历所有不包含特征 i 的子集 S
计算加入特征 i 后的边际贡献
按权重加权平均
```

**SHAP 可视化：**

**1. 瀑布图 (Waterfall Plot)**
```
显示单个样本的预测解释：

基线值 ───> +特征1 ───> +特征2 ───> -特征3 ───> 预测值
(均值)     (推高)      (推高)      (拉低)
```

**2. 蜂群图 (Beeswarm Plot)**
```
显示所有样本的特征重要性：

特征1  ●●●●●●●●●●●  (红色=高值, 蓝色=低值)
特征2  ●●●●●●●
特征3  ●●●●●
        ↑
     SHAP值（影响大小）
```

**3. 依赖图 (Dependence Plot)**
```
特征值 vs. SHAP 值：

SHAP值 |    ●  ●
       |  ●      ●
       | ●        ●●
       |●          ●
       |________________
             特征值

解读：特征值增加 → SHAP 值如何变化
```

**4. 力图 (Force Plot)**
```
推高预测     推低预测
  ↑              ↓
 ───>  ←───
[特征贡献可视化]
```

### 6.4 部分依赖图 (Partial Dependence Plot)

**原理：**

固定其他特征，只改变一个特征，观察预测变化：

```python
PDP(x₁) = E[f(x₁, X₂, ..., Xₙ)]

边际化其他特征的影响
```

**示例：**

```
预测CO₂吸附量

       |    ┌───
吸附量  |   ╱
       |  ╱
       | ╱
       |─────────────
           比表面积

解读：比表面积增加 → 吸附量先快速增加后趋于饱和
```

### 6.5 可解释性方法对比

| 方法 | 全局/局部 | 模型无关 | 考虑交互 | 计算成本 |
|-----|----------|---------|---------|---------|
| 特征重要性（树） | 全局 | ❌ | ✅ | 低 |
| 排列重要性 | 全局 | ✅ | ✅ | 中 |
| SHAP | 全局+局部 | ✅ | ✅ | 高 |
| PDP | 全局 | ✅ | ❌ | 中 |
| ICE | 局部 | ✅ | ❌ | 中 |

**推荐组合：**

```python
# 标准分析流程：
1. 特征重要性 → 识别关键特征（快速）
2. SHAP → 深入分析贡献（精确）
3. PDP → 理解趋势关系（直观）
```

## 7. 案例研究

### 7.1 案例 1：CO₂ 吸附预测

**问题描述：**

预测 MOF 在 298K、1bar 条件下的 CO₂ 吸附量（mmol/g）

**数据集：**
- 样本数：5000+ MOF 结构
- 特征：几何特征（比表面积、孔体积等）+ 化学特征
- 目标：CO₂ 吸附量

**建模流程：**

```
1. 数据准备
   ├─ 加载数据集 (QMOF / CoRE-MOF)
   ├─ 缺失值处理
   └─ 异常值检测

2. 特征工程
   ├─ 特征缩放（标准化）
   ├─ 特征选择（相关性分析）
   └─ 特征交互（可选）

3. 模型训练
   ├─ 基线模型：线性回归
   ├─ 进阶模型：随机森林、XGBoost
   └─ 超参数优化：GridSearchCV

4. 模型评估
   ├─ 交叉验证
   ├─ 测试集评估
   └─ 学习曲线分析

5. 可解释性分析
   ├─ 特征重要性排序
   ├─ SHAP 分析
   └─ 物理意义验证
```

**关键发现：**

```
重要特征（按SHAP值排序）：
1. 比表面积        (⭐⭐⭐⭐⭐)
2. 孔体积          (⭐⭐⭐⭐)
3. 最大孔径        (⭐⭐⭐)
4. 密度（负相关）  (⭐⭐⭐)
5. N原子比例       (⭐⭐)

模型性能（XGBoost）：
- R² = 0.92
- RMSE = 0.45 mmol/g
- MAE = 0.31 mmol/g
```

**物理解释：**

```python
比表面积影响机制：
- 提供更多吸附位点
- 与 CO₂ 吸附量呈正相关
- 但存在饱和效应（> 4000 m²/g 增益减小）

孔径影响：
- 最佳孔径 6-12 Å（接近 CO₂ 动力学直径 3.3 Å 的 2-4 倍）
- 太小：无法容纳
- 太大：吸附能降低
```

### 7.2 案例 2：CH₄/CO₂ 选择性预测

**问题描述：**

预测 MOF 对 CH₄/CO₂ 混合气的分离选择性

```
选择性 = (x_CO₂/y_CO₂) / (x_CH₄/y_CH₄)

x: 吸附相摩尔分数
```

**挑战：**

- 特征-目标关系复杂

**解决方案：**

```python
# 目标变换
y_transformed = log(selectivity)

# 组合特征
feature_engineering:
    - CO₂ 吸附量 / CH₄ 吸附量（经验比）
    - 极性指标（电负性、偶极矩）
    - 孔径与分子尺寸比
```

**模型性能：**

| 模型 | R² | RMSE (log scale) |
|-----|-----|------------------|
| Linear Regression | 0.65 | 0.42 |
| Random Forest | 0.81 | 0.31 |
| XGBoost | 0.87 | 0.26 |
| LightGBM | 0.88 | 0.25 |

**关键特征：**

```
Top 5 特征：
1. 极性官能团数量（-OH, -NH₂）
2. 孔限制直径 (PLD)
3. 金属中心类型
4. 比表面积
5. 骨架密度
```

   - 从简单模型开始（Linear Regression）
   - 逐步尝试复杂模型（RF → XGBoost）
   - 不要过度追求精度（避免过拟合）

   - 必须使用交叉验证
   - 保留独立测试集
   - 关注泛化能力而非训练精度

   - 理解模型决策
   - 验证物理合理性
   - 指导 MOF 设计
